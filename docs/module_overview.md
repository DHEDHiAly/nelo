# Module Overview

## `nelo.core`
Shared configuration and logging utilities.

## `nelo.inference`
Model loading/inference backend contracts for local and optional remote runtimes.

## `nelo.routing`
Routing policy interfaces that select inference backend by context and constraints.

## `nelo.memory`
Memory store contracts for user and session context.

## `nelo.multimodal`
Adapters that normalize text/audio/vision inputs.

## `nelo.backend`
Service-facing orchestration interfaces.

## `nelo.hardware`
Hardware profile and capability detection for edge-aware behavior.

## `nelo.utils`
Small shared helpers with no domain coupling.
